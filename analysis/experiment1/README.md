### Experiment 1 - Structural Analysis ###

`01_select_structures.py` Selects training-only diversified DQ heterodimers and EL=1 peptides.

`02_generate_fasta.py` Generates AlphaFold2-Multimer FASTA inputs, supports incremental expansion.

`03_extract_distance_maps.py` Extracts residue-pair distances from structures and maps their positions. 

`04_contact_architecture.py` Reports contact metrics, comparing hard:proximal:distal contact ratios.

*Note: Output from Experiment 0 is a prerequisite*
